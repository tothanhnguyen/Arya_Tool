tự nhiên qua Telegram và tự thực hiện vòng lặp phân tích --- lập kế hoạch ---
gọi công cụ --- quan sát --- điều chỉnh --- trả lời. Khác với các lớp vỏ gọi
API LLM, hệ thống đặt trọng tâm vào độ tin cậy (giới hạn bước, timeout, xác
nhận người dùng), khả năng quan sát (full execution trace) và đánh giá định
lượng (eval harness 37 test case, 9 metric, tùy chọn LLM-as-judge). Thực
nghiệm so sánh hai chiến lược điều phối (ReAct, Plan-and-Execute) trên hai
mô hình ngôn ngữ cho thấy \dots\ % PLACEHOLDER: 1--2 cau ket qua chinh.
\end{abstract}
